# CeraMirics

Repository di progettazione e sviluppo del sito ufficiale di CeraMirics.

> **CeraMirics non realizza oggetti da esporre. Realizza oggetti da vivere.**

Il progetto viene costruito per fasi, separando le decisioni di brand, UX, UI e sviluppo. L'obiettivo è arrivare all'implementazione con specifiche sufficientemente precise da non delegare all'agente di sviluppo scelte strategiche o creative non ancora approvate.

Le cartelle delle fasi successive verranno create quando inizierà il relativo lavoro. Git non conserva cartelle vuote, quindi la struttura crescerà insieme alla documentazione effettiva.

## Principio operativo

Le decisioni non vengono approvate soltanto perché esteticamente gradevoli. Devono essere coerenti con la Brand Foundation e superare la checklist di consistenza del marchio.
